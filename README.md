# Recipee
A Recipe Website to practice CSS


Harsh Da Dhabba

A simple recipe website made while learning HTML & CSS.
This project shows a couple of popular Indian sweets like Gulab Jamun and Barfi, along with their ingredients and steps.

It’s a beginner-friendly project, mainly focused on improving layout, styling, and basic UI design.

 What’s inside
Two recipe sections (Gulab Jamun & Barfi)
Ingredients + step-by-step instructions
Clean card-style layout
Image hover effect (zoom + overlay)
Gradient background for better look
🛠️ Built with
HTML
CSS

No frameworks, no JavaScript — just pure basics.
